# OV5640、MLX90640 与 LVGL RGB 屏幕预览

本例程默认使用 OV5640 的 8 位并口输出 800×480 RGB565 图像，通过 DCMIPP
采集并在 LVGL 的 4.3 寸 RGB 屏幕上预览。摄像头使用两块 PSRAM 帧缓冲
（共 1,536,000 字节），不包含自动对焦和闪光灯控制。

摄像头采集保持 800×480，默认上下翻转以修正倒置；显示时逆时针旋转 90°，
等比缩小后在右侧半屏居中显示竖向画面，不拉伸或裁剪。
如需取消翻转，可在[摄像头预览代码](applications/ov5640/camera_preview.c)中将
`OV5640_FLIP` 改为 `OV5640_MIRROR_FLIP_NONE`。

MLX90640 提供 32×24 热成像，使用出厂 EEPROM 校准并以伪彩色显示；
白色圆点和 `MAX` 温度标记最高温像素。复位后默认显示第一页：

- 第一页：左侧热成像（384×288，居中），右侧摄像头（竖向画面）。
- 第二页：仅显示热成像（640×480，居中）。

按下 USER1 在两个页面间切换，松开后才能再次切换。两个页面均持续更新热成像；
启用 USER2 保存功能时，第二页摄像头继续后台采集，但不显示。
关闭保存功能时，进入第二页后摄像头完成当前帧并暂停采集，返回第一页时自动恢复。

## 接线

断电后连接正点原子 OV5640 模组，并连接 3.3V 和共地：

| 摄像头信号 | ART-Pi II 引脚 | 摄像头信号 | ART-Pi II 引脚 |
| --- | --- | --- | --- |
| D0 | PC6 | D1 | PC7 |
| D2 | PE0 | D3 | PE1 |
| D4 | PE4 | D5 | PB6 |
| D6 | PE5 | D7 | PE6 |
| PCLK | PF8 | HREF | PG3 |
| VSYNC | PB7 | PWDN | PD6 |
| RESET | PE2 | SCL | PM13 |
| SDA | PM14 | | |

`i2c4` 是 PM13/PM14 上的软件 I²C（SCCB，7 位地址 `0x3c`），不是硬件
I2C4；确保 SCL/SDA 已有适当上拉电阻并且模组的 IO 电平兼容。
ATK-MC5640 自带时钟；如果使用没有板载时钟的其他 OV5640 模组，需要另行提供
符合该模组要求的 XCLK。PWDN 高电平关断，RESET 低电平复位。

MLX90640 和按键连接如下：

| 信号 | ART-Pi II 引脚 |
| --- | --- |
| MLX_SDA | PE13 |
| MLX_SCL（MLX_SDL） | PE12 |
| USER1 | PC0，低电平有效 |
| USER2 | PE14，低电平有效，保存照片 |
| MLX90640 电源 | 3.3V 和共地 |

`i2c5` 是 PE12/PE13 上的软件 I²C，MLX90640 默认 7 位地址为 `0x33`。
SCL/SDA 需要适当上拉到兼容的 3.3V 电平；PC0 配置为内部上拉输入，
按下时接地，并进行约 60ms 的消抖。

PE6、PM13/PM14、PD6 和 PE2 分别与 SPI4、SPI5 或 SAI 等功能复用；使用摄像头时
不要同时启用占用这些引脚的外设。PE12/PE13 与 SPI4 复用，PC0 与 SAI2 复用，
PE14 与 SPI4_NSS 复用，使用热成像、USER1 和 USER2 时不能同时启用这些冲突功能。
摄像头引脚复用位于
[MSP 用户代码区](board/CubeMX_Config/Appli/Core/Src/stm32h7rsxx_hal_msp.c)，
CubeMX 的原始 `.ioc` 分配与该接线不同。

## 编译与运行

保留原工程的 BootLoader、外部 Flash 和 PSRAM 初始化配置；使用 `project.uvprojx`
或 SCons 编译，并按原 BSP 的外部 Flash 下载流程烧录。复位后屏幕显示实时画面；
画质和帧率取决于模组、布线及 PSRAM 带宽。

配置项 `BSP_USING_OV5640` 默认开启。关闭它可恢复工程原先选中的 LVGL 演示；
`BSP_USING_MLX90640` 可单独关闭热成像及按键切换；不再使用 PE12/PE13 时，
还可在 menuconfig 中关闭软件 I²C5。

## USER2 保存到 TF 卡

使用 FAT32 格式的 TF 卡，建议断电后插入 ART-Pi II 板载 TF 卡座再开机。
工程已启用 SDMMC1 和 FAT 长文件名支持，TF 卡挂载到 `/sdcard`；
使用与 SD 卡例程一致的 PN7 检测脚，不会自动格式化卡。

两路画面准备好后，按下 PE14/USER2，会在 `/sdcard/photos` 下保存一对
24 位 BMP 图片：

```text
1_thermal.bmp
1_camera.bmp
2_thermal.bmp
2_camera.bmp
...
```

每次扫描已有照片后，从最大编号继续递增，重启不会覆盖已有照片。
保存的是各自面板的渲染画面，保留显示方向、黑边以及热图的热点圆点和 `MAX` 温度：
第一页两张图片均为 400×480；第二页热图为 800×480，摄像头仍为 400×480，
内容为后台最近采集并更新的摄像头帧。

USER2 同样采用约 60ms 消抖，长按只保存一次。后台写卡期间界面可继续更新；
屏幕显示 `Saving` 时请等待，出现 `Saved pair N` 后本次保存完成。
无卡、未挂载、空间不足或写入失败会显示错误并输出串口日志；不会报告保存成功，
也不会覆盖已有同名文件。请勿在写入期间拔卡。
可通过 `BSP_USING_PHOTO_CAPTURE` 关闭 USER2 拍照功能。

热成像采用棋盘子页模式、2Hz 刷新率，首次画面需等待两个子页。温度计算默认
发射率为 0.95、反射温度为传感器环境温度减 8°C；不同材料和环境可能需要调整
[热成像代码](applications/mlx90640/thermal_preview.c)中的参数，结果不用于医疗诊断。
颜色范围按每帧最低/最高温自动缩放（蓝色较冷、红色较热），不是固定温标。
热图默认只上下翻转，不进行左右镜像；热点标记同步变换，温度计算不变。
热图按所在页面等比放大并居中，热点及温度标签随布局调整；同一块约 600KiB
PSRAM 显示缓冲在两页间复用。

初始化失败、帧超时、短帧或 DCMIPP 错误会显示在屏幕并输出到串口。若提示 I²C
错误，请检查供电、时钟、复位及 SCCB 接线；若没有画面或出现短帧，请检查
PCLK、HREF、VSYNC 和 D0–D7。故障排除后复位开发板重试。
热成像故障会显示错误并输出串口日志；检查供电、上拉、I²C 地址与接线后，
按 USER1 切换页面可触发重新初始化。摄像头故障只在右侧区域提示，
不影响热成像页面。
